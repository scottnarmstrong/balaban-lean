## 2. Which last-step new terms are which (P7 (4.14)-(4.17), pp. 532-533)
- SOURCE (4.17): `F(h,g) = <g,h> + sum_{j<=k}<g,M^(j)(h,g)> + sum_{n=0}^m <g, M_n^(k+1)(h,g)>`; "the functions M^(j) satisfy the assumptions of (H.7)" (same constant c9, same scale j: old terms are KEPT at scale j with their old bound, no re-estimate); `M_n^(k+1)`: constant `beta_k^{-n}` for n > 0, (H.7) constant for n = 0, "n = 0 corresponds to F0^(k+1)".
- SOURCE (4.15)-(4.16): `int d psi_k rho_k = exp(-E|T| + F_{k+1,0}(h,g) + R^(k+1)(h,g)) = exp(F_{k+1,0}(h,g) + int_0^1 dt <d/dg R^(k+1)(h,tg), g>)`, normalised at g = 0. SOURCE (4.11)-(4.14): `R'^(k+1)` is the sum of R-terms of (4.9), `P^(k+1)` the exponentiated large-field gas, bounded by `(1/2) beta_k^{-m-1} exp(-kappa d_{k+1}(X))`; `R_m^(k+1) + P^(k+1) = R^(k+1)`.
- Zero-class mechanism (fluctuation Gaussian with the background `psi^(k)`, first order in psi' of `delta F_k`) = n = 0 only (`F0^(k+1)`; landed per-step analogue: `birthScale_..._rho`). n >= 1 = higher orders in psi' of `delta F_k` (OLD TERMS EVALUATED AT THE FLUCTUATING FIELD, the route of `FinalSourceAmplitude`), their cross terms with `V^(k)`, `delta E_k` in the Mayer expansion, and the g-dependent large-field gas (4.12)-(4.14).
- Answer to the last question (SOURCE, reading of (4.15)+(4.17), partly inferred): the psi'-dependent part of old terms is moved into the new terms at scale k+1 (as `delta F_k`, in `F0^(k+1)` and `R^(k+1)`); only the background value `F_k(psi^(k), g) = <g,h> + sum_{j<=k}<g,M^(j)(h,g)>` stays at scale j with the (H.7) bound. ## 3. Design of the Lean last step
Write `F_g(phi0+w) = F_g(phi0) + J_g(w)`, `J_g(w) = F_g(phi0+w) - F_g(phi0)` (PROVED machinery: `cutoffInteraction_final_phys_sub`, `norm_sub_le_of_polydisc`, `finalTerm_bound_of_sub(_ball)`, `finalTerm_bound_rpow/_inv`, `rootBound_of_perTerm`).
- (O) Old terms: `F_g(phi0) = <g,h> + sum_{j<=kf} <g,M^(j)>`; w-independent, so it comes out of the integral exactly. Amplitude: the class bound `boundM` (SOURCE: c9 (L^j)^{-((d-2)/2+gamma-alpha1)} e^{-kappa sizeJ}, j in [1,kf]) per scale j; Root-F needs exactly this per scale (A9). No new smallness is needed; locality `localM`, analyticity `analyticM`, support from `SFTermClauses`. Missing: identification of `F_g(phi0)` with the class terms (OPEN, item 5).
- (N) New terms: `Lnew(g) = log int d gamma_box exp(G0 + J_g) - log int d gamma_box exp(G0)` (G0 = g-independent part of the exponent), with `Lnew = sum_{n>=0} M_n^(kf+1)`.
  - Naive route (landed, W809): `A <= 2 B B_cut beta_k^{-1/2} rho/R_phys`, `B = sup|J|` on the polydisc, `rho = p1(beta)`. FAILS the Root-F requirement: needed `A <= C0 beta_k^{-p}` with `p(d-2) >= (d-2)/2 + delta` (FINALAMP; p >= 5/8 for delta = (d-2)/8). Failing inequality: `beta_k^{-1/2} rho B <= c beta_k^{-p}` iff `rho B <= c beta_k^{-(p-1/2)}`; with `B ~ c9` (the j = 1 term) and `rho >= 1` the ratio LHS/RHS is `~ rho B beta_k^{p-1/2} -> infinity` for every `p > 1/2` as k grows. In the c9 L^{-(kf+1)e} form: the excess factor is `L^{(kf+1) delta + (d-2)/2} rho/ sqrt(beta0)` (> 1 for large k).
  - Why the per-step theorem is better: it also has the sigma-Schwarz `1/R_g = b^{-s}` with large `R_g`, available only because the source enters the observable activity LINEARLY (tilt). At the last step F is analytic in g only on `||g||_1 < R` (fixed), so a large g-disc is not available: that factor has no analogue (OPEN, no source for it).
  - Candidate (OPEN, conditional on G0): second-order Schwarz. Subtract the linear part `J_1(w) = <dJ(0), w>`; `|J - J_1| <= B (|w|/R)^2 R/(R-|w|)`; gives `beta_k^{-1} rho^2 B/R_phys^2` (p = 1 minus a log; enough). The linear part is odd in w; it integrates to zero against the centred symmetric box Gaussian but NOT against `e^{G0}` with the odd cubic part of `V^(k)`; the cross term is `<J_1 , G0_odd>_gamma` of size `beta^{-1/2} * beta^{-1/2}` (G0_odd ~ beta|w|^3 ~ beta^{-1/2}); this matches P7 "n = 1 carries beta_k^{-1}". Fails (no gain) if the final integrand puts the cubic term in the same activity as J.
