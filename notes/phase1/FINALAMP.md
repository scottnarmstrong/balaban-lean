## 2. Where the smallness comes from (question 2)
- PROVED/SOURCE: Root-F's identity is for log(Z(g)/Z(0)) (frozen file, Root-F statement); the papers normalize at g = 0: P7 (4.16) int dpsi_k rho_k (g = 0) = 1, and (4.15) writes F_{k+1}(h,g) = <g,h> + int_0^1 dt <d/dg R^(k+1)(h, t g), g>. This is the form of `kf0Deriv F g u b = int_0^1 d_{g_b(u)} F(t g) dt` in `finalTerm_bound`. The g-independent parts (energy, log det C, V^(k)) drop; only the g-dependent part needs an amplitude.
- SOURCE (P4 (2.52)-(2.53), p. 694): the new g-dependent term is F_0^(k+1)(g) = beta_k^{-1/2} int dt int dmu_{1,t}(psi) <(d/dpsi') delta F_k (beta_k^{-1/2} C^1/2 t psi), C^1/2 psi>. Smallness: the explicit factor beta_k^{-1/2}, and delta F_k = F_k(psi^(k) + psi', g) - F_k(psi^(k), g) vanishes at psi' = 0 (Gaussian-mean-zero in psi' at first order).
- SOURCE (P4 Prop 2.2, p. 696): F_0^(k+1) satisfies (H.7) for j = k+1 with c_9 replaced by const beta^{-5/8+alpha_1} <= (1/2) beta^{-1/4}, kappa -> 2 kappa - 4 - 6 kappa_0. So the n = 0 term has the (H.7) size c_9 L^{-j((d-2)/2+gamma-alpha_1)} (H.7, p. 679) times a small constant; delta = gamma - alpha_1. The proof is deferred to P3/P6 localization papers (not read): OPEN for Lean.
- SOURCE (P7 (4.17), p. 533): M_n^(k+1), n = 1..m, carry the constant beta_k^{-n}; n = 0 carries the (H.7) constant. The large-field gas (4.12)-(4.14): activities <= (1/eps^2) exp(-p_2(beta_k)) exp(-(3/2 kappa - 2 kappa_0 - 1) d_{k+1}(X)), terms of P^(k+1) bounded by (1/2) beta_k^{-m-1} exp(-kappa d_{k+1}(X)): amplitude is any power of beta_k^{-1}.
- Hence: the smallness is NOT from the determinant ratio (the papers have none) and NOT from J(1) - J(0) as such; it is from the g-dependent part of the old interaction (delta F_k) after normalization. The amplitude is beta_k^{-n} (n >= 1) for the Taylor terms and beta^{-1/4} times the (H.7) size for the n = 0 term. A <= C_0 beta_k^{-2} (hypothesis of `finalTerm_bound`) is NOT stated in the papers: it holds for the terms with n >= 2 only. For n = 0, 1 the source gives beta^{-1/4}(H.7 size) and beta_k^{-1}.
- PROVED (arithmetic, `betaK` = beta0 L^{k(d-2)}): beta_k^{-p} <= c L^{-(k+1)((d-2)/2+delta)} holds for all k iff p (d-2) >= (d-2)/2 + delta (up to the constant L^{(d-2)/2+delta}); with delta = (d-2)/8 (RootParams) p >= 5/8 suffices, so beta_k^{-1} is enough and beta_k^{-1/2} is not (fails at large k). The landed `betaK_inv_sq_le` is the case p = 2; the case p = 1 needs a new theorem, `finalTerm_bound` is not to be edited.
