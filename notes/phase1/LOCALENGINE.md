## T2. The two-generator trace route

**PROVED (conditional setup).** Let $G_A$ be the ambient whole-level generator, $B=B_Y=\mathbb B_{k+1}(Y)$, and $T_Y$ the linear trace of **both** raw fields to $Y=\operatorname{sitesOf}T'\subset\Omega_1(B)$. Write $U_A$ for the ambient relative chart (with any fixed source included) and $U_B$ for `XiDom B` viewed on its relative layer-constant subspace. Assume the specified coefficient $c_A$ is analytic and bounded on $U_A$ and has the exact locality property $T_Yq=T_Yq'\Rightarrow c_A(q)=c_A(q')$. `Fluctuation/CoeffFamilyLocExp.lean:45–58` takes this exact locality as `hloc`; its generic theorem does not prove it for every physical coefficient. `Inhabited/E1ParamRawLocal.lean:586ff` proves an exact restriction ingredient for a marked term, while `ObsFamilyJoint.lean:41–42` still describes a thickened-data locality premise for the observable. Apply the following route only to a coefficient for which exact $Y$ locality has actually been established.

**OPEN (decisive chart-reachability lemma).** The needed assertion is
$$\tag{TR} \forall p\in U_B\ \exists q\in U_A:\quad T_Yq=T_Yp.$$
It is local-to-ambient **trace** reachability, not the ambient-to-local inclusion above. A useful linear prerequisite is $T_Y(\operatorname{rawSub}B)\subseteq T_Y(\operatorname{rawSub}G_A)$, with a continuous complex-linear right inverse $R$ on the left trace space; this needs the top-block alignment of $Y$. Given (TR), choose $q_0$ above $p_0$ and put $S_{p_0}(p)=q_0+R(T_Yp-T_Yp_0)$. Then $T_YS_{p_0}(p)=T_Yp$; relative openness of $U_A$ gives a relative neighbourhood $V_{p_0}\subset U_B$ mapped into $U_A$. This $S_{p_0}$ is affine holomorphic. Exact $Y$ locality makes $c_B(p):=c_A(S_{p_0}(p))$ independent of the chosen section and locally analytic in the relative subspace; the ambient uniform bound transfers without a new prefactor. For the class's **full-space** `AnalyticOnNhd`, additionally project the full trace linearly onto $T_Y(\operatorname{rawSub}G_A)$ (identity on the local trace space) and define the descended function on the open trace image $T_Y(U_A)$, extending it arbitrarily off that image. Its composition with the projected trace is analytic in a full neighbourhood of every $p\in U_B$, because $T_Y(U_A)$ is open in the finite-dimensional trace image. This proves an **abstract conditional descent**, but (TR), the trace-space inclusion and equality with the intended physical/local coefficient are **OPEN**.

**REFUTED (a proposed easy extension).** A fixed `unitBg` outside $Y$ cannot accommodate every $p\in U_B$: its real orientation need not match the boundary data, and gluing creates interface differences. The raw chart's norm condition is an **inequality**, so affine interpolation does not violate an exact input unit equation; it can nevertheless violate `InPsiTilde.r1/r2/r3`, `InPsiTildeC.c1/c2`, and the solution bounds of `XiC`. The *solution* field is exactly constrained in the variational problem. The map $z\mapsto z/\sqrt{z\cdot z}$ is holomorphic in a neighbourhood of each real unit vector (`Background/LocalSolution.lean:38–39` uses this formula), but a single normalization does not repair boundary gradients or prove the canonical ambient solution estimates. It is therefore **REFUTED** that cut-off interpolation plus normalization alone proves (TR).

**PROVED (precedents and limit).** `BgData.clip` enforces support after block-constancy; it supplies no chart extension. `CoeffFamilyLocExp.exists_rawProj` (:120–125) is a continuous linear retraction **onto the ambient `rawSub`**, identity on that subspace; it does not map local `XiDom` into ambient `XiCRaw`. `Fluctuation/RenormThetaDatum.lean:72–99` gives the analytic scalar perturbation `renThetaDatum`; `Inhabited/StepTowerRadius.lean:108–124`, `renDatum_half_mem_xiCData`, proves that particular ambient family stays in `XiCData` at half radius. These prove neither (TR) nor an extension for arbitrary local $p$. A class restricted to such perturbations would be a different domain and would need explicit author approval before replacing the current `xiFieldDom`/`XiDom` clause.
