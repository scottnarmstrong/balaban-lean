It is **REFUTED** that this means only checking a few inequalities at $Y$ while silently keeping the ambient solution: changing $G$ changes the variational problem and typed datum.

**OPEN (two-generator formulation).** One may keep the ambient level set `Gp` for `unitPts`, the hat covariance and the fluctuation integration, while using $B_Y$ for the output class chart. Then a theorem must take every $p$ in an open neighbourhood of each point of `XiDom B_Y` to an ambient admissible datum $S(p)$, holomorphically in $p$, with `S(p)` agreeing with $p$ on every live raw/hat read (at least `compY` and its typed collar reads), and the same rooted coefficient on overlaps. Exact locality on the **global** chart then makes $f\circ S$ independent of the chosen section; global bounds transfer only if $S(p)$ stays in the bounded global domain. This is an **OPEN** special extension lemma for the actual `XiC`: zero extension can violate the unit-length datum condition and change the solution (`GENERATOR.md §3`), and no local-to-global analytic section was found. General sharp locality plus global analyticity alone is **REFUTED** as a shortcut. If the section were proved, one would define and glue a new extension on the local chart; it would not automatically prove that the old total raw formula is analytic at arbitrary local-only points.
