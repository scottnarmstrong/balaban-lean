## 2. Source translation and the failed alternatives

**PROVED:** The fine-torus embedding is $z\mapsto\operatorname{blockPt}(j,z)=L^jz$ modulo the torus (`Def6Terms.lean:198`); `unlift j` returns the centred $j$-block coordinate (`:171`). **REFUTED:** Option (i), all fine $x$ with $a_j(\operatorname{unlift}j(x-y))$, is the paper's A-term. For a field constant on each complete $j$-block, an aligned centre $y$ and a nonzero interaction between two blocks give $L^{jd}$ identical copies of each aligned $x$ contribution. For a general fine field it additionally reads non-aligned values absent from the paper. `unlift` being block constant is a property of the **coefficient**, not a support indicator.
