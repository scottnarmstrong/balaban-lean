## T3. Proposed-package defects and refutation checks

**PROVED / REFUTED.** `Consts.Admissible` permits `α₁≥γ` (`Def6.lean:63–67`); `GsSpecClass.lean:111–124` even sets `γ=α₁=1/4` for a zero-term witness. Such a class has no positive Root-F power gap, so the implication “every admissible class gives Root-F's δ” is **REFUTED**. This does not falsify the class or its witness. Root-F needs only **one** class chosen with `α₁<γ` (and the paper's stronger `<γ/2`); no change to `Consts.Admissible` is needed for existence.

**PROVED / REFUTED.** `Consts.c₉` is a real field, not definitionally `β^{-1/4}` (`Def6.lean:50`). The latter appears explicitly in `Observables/LayerDictionaryBound.lean:19,67` and `LayerV2Dictionary.lean:57,183`, and in the scalar comparison `Fluctuation/ObsScalarTilt.lean:234–294`; `GsSpecClass.lean:117` instead uses `c₉=1`. Hence “Lean nowhere uses the β-dependent convention” is **REFUTED**. What fails Root-F's order is setting **the fixed class field** `P.c₉` equal to `β^{-1/4}` after `β` varies. A β-dependent *estimate* is useful: for a fixed small `P.c₉>0`, enlarge `β₀` until `β^{-1/4}` (with fixed prefactors) lies below it for all `β≥β₀`.

**PROVED.** `P.κ` can be selected after a common tower as any number in `[c₁κroot,κout−loss]` when that interval is nonempty. Thus `StepTowerG` need not store `P.κ`; it must expose enough output-rate room and share the same rate with the physical step. The alternative choice “choose `P.κ` first, then `κ₀` large enough” is also numerically valid but asks the producer to take a class-rate floor. The present `κmin` field controls only `κint` and cannot certify either route.

**PROVED / OPEN.** Mathematically the positive-scale class's `P.m₀` and the physical cover's `m₀` must be **one selected integer**, because `IsPolyDom P.m₀ j X`, `sizeJ P.m₀ j X`, `cellSide L m₀ m₁ j`, and `M=L^{m₀+m₁}` must refer to the same blocks (`Def6.lean:267–272`; `PolymerGeometry.lean:cellSide`). `zeroClass.m₀=0` is a separate degenerate input convention (`SMALLTORUS.md:19`). **OPEN:** an equality `P.m₀=T.m₀` and general physical cover/output wrappers are absent; adding a second unconstrained `m₀` would create a false bridge.
