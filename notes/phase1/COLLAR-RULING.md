# The collar data in P7 Lemmas 2.3–2.4

## Ruling

The estimate (2.48) of P7 is an estimate on the **blocks of the window generating set** $\mathbb B_{k_1,k}$, including its layers $k_1,\ldots,k$; it says nothing about an independently supplied layer-0 datum on the Dirichlet collar of $\Omega_1(\mathbb B_{k_1,k})$. The collar is outside the variational *sites*, but its values enter the boundary bonds and therefore the background solution. It cannot simply be omitted from a data perturbation theorem. In particular, the present `psiTilde` choice of the fine field $\psi_0(x)$ on that collar and the composed `psiZeroWin` choice do not coincide by definition or by P7 Lemma 2.3. Neither P5 (1.24) at layer 0 nor P7 (2.43) turns their difference into $O(\hat W_k\delta_{k_1})$.

There are two mathematically sound ways to use (2.49). One is to specify the *same* collar datum for the two window backgrounds and prove that this is the boundary datum used by the original action. The other is to retain the two physical collar data and establish a separate $O(\hat W_k\delta_{k_1})$ bound there, with the same weighted profile needed by the response estimate. P7's printed Lemmas 2.3–2.4 alone establish neither identification. Thus the currently landed `DataChangeBound` is a genuine extra premise, not a consequence of (2.48′).

## Source evidence and the actual data

P7 p. 500 (2.13) defines the window $\mathbb B_{k_1,k}$; p. 500 (2.14) uses composition of backgrounds between generating sets. P7 p. 508 (2.40) defines $\phi_k^0=\phi_k(\mathbb B_k(U_k);\tilde\psi_k^0)$ and $\psi^0_{k_1,k}=\psi(\mathbb B_{k_1,k},\mathbb B_k(U_k);\tilde\psi_k^0)$. P7 p. 508 (2.43) bounds $|\psi^0_k(z)-\psi^0_{k_1,k}|$ on $k$-blocks in $\Omega_k^c$ by $4K_1K_6\delta_k$ and (2.44) gives equality on the indicated $k$-blocks in $\Omega_k\cap U_k^\sim$. P7 pp. 508–509 (2.46)–(2.48) then define $\delta\psi=\tilde\psi-\psi^0_{k_1,k}$, show that it vanishes on $\mathbb B_{k_1,k}\cap\Omega_k$, and bound it on $\mathbb B_{k_1,k}\cap\Omega_j\cap\Omega_{j+1}^c$ for $k_1\le j<k$. In the proof on p. 509, $\tilde\psi(x)$ is explicitly the window-block value $\psi_j(y)$ for $x$ in that set. No value outside $\Omega_1$ appears in this proof. P7 p. 509 Lemma 2.4, (2.49), invokes the proof of P3 Proposition 2.1 with this profile; P3 Proposition 2.1 is the localization/interpolation result on pp. 56–57, not an assertion that missing collar differences vanish. The reconstruction's III.4.6–III.4.7 repeats the interior profile as (2.48′) and uses it for (2.49′); it likewise supplies no collar statement.

The P2 background convention made explicit in `Balaban/Background/Data.lean` is that the unknown field lives on $\Omega_1$, while the action extends it by $\Psi$ on $C(\Omega_1)$ (`barField`, `action`). Thus a window background really has data on $\Omega_1\cup C(\Omega_1)$. On the window interior, the first datum is $\tilde\psi=Q^*(\mathbb B_{k_1,k},\mathbb B_k)\psi$ and the second is the composed field $\psi^0_{k_1,k}$. On its collar, the *second* datum in the landed model is the P2 (4.21) composition boundary value: `composeField_of_collar` in `Balaban/Background/Composition.lean` gives $\bar\phi_k^0(x)$, which means $\phi_k^0(x)$ if $x\in\Omega_1(\mathbb B_k(U_k))$ and the lifted $k$-block datum $\psi_k^0(z(x))$ otherwise. The *first* datum in `DeltaPsiDef.lean:psiTilde` is $\psi_0(x)$ there. Those are different expressions. The collar is outside the window's variables, but it is not outside the window background's boundary data.

P5 §1 (1.24) compares adjacent multiscale blocks at the **index of that bond**. At a layer-0 bond it gives an $O(\delta_0)$ comparison, not an $O(\delta_{k_1})$ comparison. P7 (2.43) compares $\psi^0_{k_1,k}$ with $\psi_k^0$ by $O(\delta_k)$, and does not compare either one with $\psi_0$. Consequently the two cited estimates cannot close a collar bound of size $\tau_1=C_{23}\hat W_k\delta_{k_1}$.

An elementary test exposes the logical gap. Keep all window block values and all $k$-block reference values equal to a unit vector $e$, so the interior (2.48) and terminal equality hold with zero difference; take a collar fine field $\psi_0(x)$ rotated from $e$ by $c\delta_0$ (and extend it over the adjacent exterior fine sites so that the layer-0 restrictions hold). The reference composition has collar value $e$ in the constant-background case. This respects an $O(\delta_0)$ layer-0 small-field condition, but its collar difference is comparable to $\delta_0$ and cannot be bounded by a constant times $\hat W_k\delta_{k_1}$ uniformly in $k_1$. The same conclusion applies to the exact `DataChangeBound` statement in `DeltaPhi.lean:124–131`. This test is an implication counterexample, not a claim that every such field occurs in a particular P7 window geometry; a stronger geometry or a special boundary convention would have to be proved and supplied.

## Correct formulation and bound

Write $G=\mathbb B_{k_1,k}$, $C_G=C(\Omega_1(G))$, $D^{\rm ph}$ for the data used by the physical window background, and $D^0$ for the reference data. Define the perturbation on the **whole data set** by
$$
\Delta\Psi(x)=D^{\rm ph}.\Psi(x)-D^0.\Psi(x),\qquad x\in\Omega_1(G)\cup C_G.
$$
On $\Omega_1(G)$, this is P7 (2.46), with (2.47) and (2.48′). On $C_G$ one must choose and verify one of the following:

* **Common Dirichlet data.** Set $D^{\rm ph}.\Psi(x)=D^0.\Psi(x)=\bar\phi_k^0(x)$ on $C_G$. Then $\Delta\Psi|_{C_G}=0$ exactly. This is valid for P7 only if a boundary-data identity shows that the original $\phi_k(G;\tilde\psi)$ uses this common value; changing the collar of only one background changes its boundary bonds and is not an identity of the original expression.
* **Physical collar data.** Keep the actual first collar field $\Psi^{\rm ph}_{\partial}$ and the composed second value $\bar\phi_k^0$. Prove, as a separate thickened-window estimate,
  $$\sup_{x\in C_G}|\Psi^{\rm ph}_{\partial}(x)-\bar\phi_k^0(x)|\le C_{\partial}\hat W_k\delta_{k_1}.\tag{C}$$
  For a weighted response estimate, use the collar layer/profile in its actual operator norm; for example set $\tau(0)=C_{\partial}\hat W_k\delta_{k_1}$ and $\tau(j)=C_{23}\hat W_k\delta_j$ for $k_1\le j\le k$, and prove the adjacent-profile and smallness conditions required by the response theorem. If the response API identifies the collar with layer 1, it must accept $\tau(1)\ge C_{\partial}\hat W_k\delta_{k_1}$ rather than silently use $C_{23}$.

The first option yields the landed collar clause of `DataChangeBound` for every nonnegative $\tau(1)$. The second yields it with $\tau(1)=\max(C_{23},C_{\partial})\hat W_k\delta_{k_1}$. In either case, the perturbation theorem then gives P7's (2.49)-type bound with a constant proportional to the appropriate profile constant, subject to its smallness and separation hypotheses. P7's printed $C_{24}=2K_3C_{23}$ is justified only if the collar change is zero or the separate collar estimate is absorbed without increasing that constant. The exponential decay from the $\Omega_k$ agreement region additionally needs the weighted zero/source localization used in the proof of P3 Proposition 2.1; a plain supremum estimate alone does not create that factor.

For the landed implementation, `deltaPsi` in `DeltaPsiDef.lean` currently sets the perturbation to zero off $\Omega_1$ **without** changing `psiTildeData` or `windowData` there. Hence it is not the full data difference. Either define both `BgData` objects with a common verified collar, or retain the actual collar values and add a proof of (C) plus a full-data perturbation field. `DeltaPhi.lean:DataChangeBound` correctly asks for the missing collar comparison but its current value `psiTilde = ψ₀` should not be called a consequence of P7 (2.48′). The class and fluctuation arguments may cite (2.49′) only after this boundary-data bridge is closed.
